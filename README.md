For Minecraft 26.3

Eggblock makes every chicken lay a random item instead of laying eggs. So if you play in a Void superflat preset, you can only gain new materials by hatching new chickens and hoping they give you something good. Since this data pack was designed to be played with the Void superflat preset, every player spawns with a regular chicken that lays regular eggs, making it possible to start farming new chickens. Eggs also hatch into fully-grown adult chickens, and have an increased hatching rate of 50%, instead of the usual 12.5%, however there is no chance for three chickens to spawn.

Should you need to summon a new regular egg chicken for any reason (perhaps you lost yours), run the command `/function eggblock:summon_egg_chicken`
